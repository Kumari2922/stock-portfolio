Definitions and data method
  • Value: fixed shares × daily CAD close, summed across the seven holdings. Shares = initial amount / first CAD close.
  • Total return: ending value / starting value − 1. CAGR: the constant annual growth rate that connects those values over the elapsed years.
  • Volatility: sample standard deviation of daily returns × √252. Sharpe: average daily return above 3%/252, divided by daily standard deviation, × √252.
  • Drawdown: value / highest earlier value − 1. Daily gaps carry the previous available close forward; no future prices are used.
  • All raw listings are quoted in USD. Each price is converted using the repository's Bank of Canada USD/CAD series. RY and TD are US listings; SHOP is excluded.
  • These seven stocks were selected with their outcomes known. Source documentation calls the prices split-adjusted; that adjustment was not independently audited here. Dividends and a market benchmark are absent.
  • Dashboard reads the committed SQLite snapshot. It does not fetch live prices. Regenerate the dashboard after refreshing the pipeline. Fractional split-adjusted share units are allowed.
